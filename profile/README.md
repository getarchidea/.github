## The browser

### [Archidea](https://github.com/getarchidea/archidea) — a calm, fast browser for the Mac

Spaces, pinned tabs and folders — the ideas that made Arc feel like home — in a native
Swift and AppKit app on top of Chromium. Every site works. Every Chrome extension works.
Nothing phones home.

## What we believe

| | |
|:---|:---|
| **Native first** | Real Mac apps — AppKit, not a web page in a frame. The interface is fast because it isn't HTML. |
| **Light** | Software that gives memory back, not software that collects it. Fifty pinned tabs shouldn't cost fifty processes. |
| **Private by default** | No accounts. No telemetry. No features that quietly read your data. The network is for the pages you visit, nothing else. |
| **Open** | GPL-3.0. Read it, fork it, build it yourself. If we disappear, the browser doesn't. |
