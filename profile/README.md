# Get Archidea

An open-source browser for macOS, inspired by Arc and Dia.

Arc is being discontinued, and we want to keep its browsing experience alive. Get Archidea is an independent project focused on recreating Arc as closely as possible while exploring ideas from Dia.

Built with Swift and Chromium.

## What we're building

- A familiar Arc-inspired interface and browsing experience
- A native macOS application
- Chromium-based browsing
- No mandatory accounts
- No telemetry

## Project

Get Archidea is an independent, community-driven project. It is not affiliated with The Browser Company or Dia.

Our goal is simple: preserve the browser experience people love and keep it open source.

**Keep Arc's spirit alive.**
